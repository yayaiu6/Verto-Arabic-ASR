# Verto Arabic ASR — إصدار تجريبي

تفريغ عربي مصري وعربي/إنجليزي مختلط محليًا داخل المتصفح. تحويل INT8 وتطبيق المتصفح بواسطة يحيى معروف، اعتمادًا على Metro-ASR Small بواسطة Mohammed Aly.

الموديل 69.46 MB، والحزمة مع ملفاتها المساعدة 69.93 MB. كود التكميم خاص وغير منشور؛ المستودع يحتوي تطبيق المتصفح واختباراته فقط، والأوزان تُنشر على Hugging Face.

شغّل `npm ci` ثم `npm run build` ثم `npm start`، وافتح `http://127.0.0.1:4180`. سجّل بالميكروفون أو ارفع ملف صوت من 0.5 إلى 30 ثانية. OGG/Opus لرسائل واتساب مدعوم، مع محوّل محلي عند فشل decoder المتصفح. PCM الخام يحتاج إعدادات مصدره.

الملفات تُحفظ بعد التحقق من بصمتها لإعادة استخدامها، لكن المتصفح قد يمسح التخزين. الصوت والنص لا يُرفعان لسيرفر ولا يُحفظان في الكاش. العمل دون إنترنت يتطلب تنزيل التطبيق والموديل وملفات التشغيل المطلوبة مسبقًا.

هذه Preview: تقييم WER/CER البشري غير مكتمل واستهلاك الذاكرة غير مقاس. لا ندّعي الحفاظ الكامل على الدقة أو دعم كل اللهجات. ترخيص كودنا MIT؛ FFmpeg الاختياري له GPL مستقل. راجع [التوثيق الإنجليزي](README.md) للتشغيل باستخدام Docker والتراخيص والقياسات.
